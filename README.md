# LLM-Remote-Assistant

An AI-powered mobile assistant designed to remotely control a personal computer using natural language commands. This project leverages a polyglot microservice architecture to achieve a flexible, scalable, and powerful remote assistance tool.

---

## Project Status

**Current Phase: Milestone 2 Complete**

The project has successfully completed its second major milestone: **Checkpoint 2 - First Intelligence**.

The core functional loop of the application is now operational. The system can now accept a natural language command from a client, dynamically generate Python code using a Large Language Model, transmit that code back to the client, execute it, capture the output, and report the result back to the server.

### Key Achievements in Checkpoint 2:
- **LLM Integration:** The Python Orchestrator is successfully connected to an LLM provider (Groq) via a flexible, provider-agnostic client module (`llm_client.py`).
- **Dynamic Code Generation:** A robust system prompt has been engineered to instruct the LLM to generate executable Python code and an "intent" summary, delivered in a reliable JSON format.
- **Remote Code Execution:** The PC Agent is now capable of receiving, parsing, and (unsafely, for now) executing the code generated by the LLM.
- **Full Feedback Loop:** The agent can capture the output or errors from the executed code and report them back to the server, completing the `Command -> Generate -> Execute -> Report` cycle.
- **gRPC Migration:** Inter-service communication between the Go and Python services has been upgraded from REST to high-performance gRPC, making the backend more robust and scalable.

### Previous Milestone: Checkpoint 1 - The Nervous System
The foundational infrastructure was established, including Docker orchestration, a polyglot microservice stack (Go, Python), and a verified end-to-end communication channel.
